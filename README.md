# ADLSM

Aplicación web interna para la gestión deportiva de Agrupación Deportiva La Salle Montemolín.

La aplicación utiliza el proyecto Supabase existente como fuente de datos y mantiene el histórico por temporadas.

## Áreas
- Dashboard
- Personas
- Equipos
- Temporadas
- Partidos
- Competición
- FAB / FEB
- Usuarios

El frontend es estático y está preparado para GitHub Pages.
